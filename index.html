1. HTML5 (Estructura)

Define el contenido y la esqueleto de la página web mediante etiquetas semánticas.

  • Semántica: Uso de <header>, <main>, <article> y <footer>.
  • Formularios: Entradas de texto, botones y campos de captura de datos.
  • Multimedia: Inclusión de imágenes (<img>) y videos.

2. CSS3 (Estilos y Diseño)

Maneja la apariencia visual, la disposición de elementos y la adaptabilidad a pantallas.

  • Flexbox: Alineación y distribución eficiente de elementos en filas o columnas.
  • CSS Grid: Maquetación bidimensional para esquemas complejos.
  • Diseño Responsivo: Adaptación de la interfaz mediante Media Queries.

3. JavaScript (Interactividad)

Aporta dinamismo, manipulación de la interfaz y procesamiento de datos en el cliente.

  • DOM: Selección y modificación dinámica de elementos de la página.
  • Eventos: Respuesta a acciones como clics o escritura del usuario.
  • Asincronía: Consumo de APIs mediante Fetch y promesas.
